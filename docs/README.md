# `docs/` — repo polish & launch package

This folder is the launch kit. Open in this order:

1. **[DEMO_CHECKLIST.md](DEMO_CHECKLIST.md)** — exact GIFs and screenshots to
   record, with the queries to type and the file names to save. Do this first
   so the README links resolve when you push.
2. **[LINKEDIN_POST.md](LINKEDIN_POST.md)** — three drafts (short, medium, long)
   plus posting tips. Pick one.
3. **[MARKETING_COPY.md](MARKETING_COPY.md)** — GitHub About text, CV bullets in
   three lengths, the 90-second interview walkthrough, and pre-prepared
   answers for the tough questions.

`media/` is where every screenshot and GIF lives. The README and LinkedIn
post reference these exact filenames:

- `media/demo.gif` — hero (30–60 sec pipeline walkthrough)
- `media/ablation.png` — verifier-on vs verifier-off bar chart
- `media/architecture.png` — Mermaid diagram exported as PNG
- `media/refusal.png` — out-of-distribution refusal screenshot
- `media/pipeline_panel.png` — per-skill timings shot

If you rename anything, update both the root README and `LINKEDIN_POST.md`.
